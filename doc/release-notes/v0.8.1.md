# fSpy Reframe 0.8.1

This release updates the Windows installer so fSpy Reframe can be installed either for the current user or for all users on the machine.

## Changes

- Switch the Windows NSIS installer to assisted mode.
- Keep current-user installation available and selected by default.
- Allow elevated all-users installation into the machine-wide program files location.
- Support silent deployment with NSIS install mode switches such as `/allusers` and `/currentuser`.

## Validation

- Windows CI verifies linting, builds, tests, packaging and packaged-app smoke launch before release assets are published.
