# v0.6.0-ue

## Highlights

This release focuses on smoother day-to-day editing and safer project/file handling while keeping the existing Unreal Engine camera-matching workflow intact.

## What's New

- Numeric fields now apply valid edits when the field loses focus, including when tabbing to the next control.
- Save Project and Save As now use a clear `.fspy` save dialog with an `untitled.fspy` default for new projects.
- Saved project paths automatically get the `.fspy` extension when the user does not type one.

## Fixes

- Fixed precision dragging with `Shift` so handles no longer keep an offset after releasing and grabbing them again.
- Reset precision-drag state when the window loses focus or the document becomes hidden.
- Restored windows now fall back to a centered default size if the saved bounds are offscreen or barely visible.
- Avoid defaulting Save As to the bundled example project path.

## fSpy-UE Workflow Preserved

- Unreal Engine target preset.
- Target scene orientation options.
- Unreal-friendly camera position, rotation and FOV display.
- Raw fSpy camera JSON export.
- Target camera JSON export for Unreal workflows.
- Drag/drop image and `.fspy` project loading.
- Fullscreen `F11` workflow.

## Validation

- `npm.cmd run verify`
- Manual app testing:
  - numeric fields with click-away and `Tab`
  - `Shift` precision dragging and re-grabbing handles
  - JPEG files with EXIF orientation metadata
  - startup splash screen
