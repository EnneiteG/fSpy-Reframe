# v0.5.0-ue

## Highlights

This release updates fSpy-UE's dependency stack after the `v0.4.0-ue` modernization release while preserving the Unreal Engine camera-matching workflow.

## What's New

- Updated the dependency stack:
  - React 19 and React DOM 19
  - React Konva 19 and Konva 10
  - TypeScript 6
  - Jest 30
  - ESLint 10 with flat config
  - Webpack CLI 7
  - GitHub Actions using Node 24-compatible actions
- Updated all remaining direct npm dependencies so `npm outdated` reports no pending updates.
- Kept `ts-jest` and `ts-loader` compatible with TypeScript 6.
- Removed obsolete Yarn, Babel and TSLint maintenance references.

## Fixes

- Fixed exported files missing extensions when the user saves without typing one manually.
- Added default save names for raw camera JSON, target camera JSON and project image exports.
- Project image export now detects common image formats and uses an appropriate extension when possible.

## fSpy-UE Workflow Preserved

- Unreal Engine target preset.
- Target scene orientation options.
- Unreal-friendly camera position, rotation and FOV display.
- Raw fSpy camera JSON export.
- Target camera JSON export for Unreal workflows.
- Drag/drop image and `.fspy` project loading.
- Fullscreen `F11` workflow.
