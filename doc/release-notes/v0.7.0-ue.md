# v0.7.0-ue

## Highlights

This release adds a free reference distance workflow for calibrating scale from arbitrary measurements on a chosen 3D plane.

## What's New

- Added a `Free` option to the Reference distance menu.
- Free reference distance mode lets you place both distance handles independently in the image.
- Added a Reference plane selector for free measurements:
  - Ground plane
  - Vertical XZ plane
  - Vertical YZ plane
- Free measurements are projected onto the selected 3D plane and used to scale the solved camera.
- Existing axis-based reference distance mode remains available and unchanged.

## Compatibility

- Existing `.fspy` project files load with default values for the new free reference distance fields.
- Target preset and Unreal scene orientation mappings are preserved for axis and plane selection.

## Validation

- `npm.cmd run verify`
- Manual app testing of the new Free reference distance controls.
