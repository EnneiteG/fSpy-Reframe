# v0.8.0

## Highlights

This release renames the fork to fSpy Reframe. The new name reflects the broader direction of the project: a maintained fSpy fork for camera matching workflows across multiple target applications, not only Unreal Engine.

## What's New

- Renamed the application and repository branding from fSpy-UE to fSpy Reframe.
- Removed the `-ue` suffix from the release version scheme. Future releases use tags such as `v0.8.0`.
- Added a Blender target preset.
- Added Blender XYZ Euler camera rotation output in degrees.
- Kept the existing Unreal Engine target preset, scene orientation options and target camera JSON export workflow.

## Fixes

- Fixed Blender preset rotation output so it matches Blender's XYZ Euler camera rotation convention.
- Fixed the development and packaged Windows app icon so the title bar and taskbar use the same fSpy icon shown on the splash screen.
- Smoothed `Shift` precision dragging by constraining Konva drag positions directly instead of correcting the control point after the raw pointer movement.

## Validation

- `npm.cmd run lint`
- `npm.cmd test -- tests/gui/gui_tests.ts`
- `npm.cmd run build-dev`
- GitHub Windows CI for the Blender preset and precision dragging changes.
