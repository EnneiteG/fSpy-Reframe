# v0.7.1-ue

## Highlights

This release adds minimal AVIF image support while preserving the existing image import and project export workflow.

## What's New

- Added AVIF to the Open image file filter.
- Added AVIF detection for imported project images.
- Project image export now keeps the `.avif` extension when the stored image bytes are AVIF.
- Image loading now provides an `image/avif` MIME type for AVIF sources.

## Fixes

- Avoid exporting AVIF image bytes with a default `.png` filename.

## Validation

- `npm.cmd run verify`
- Manual app launch after AVIF support changes.
