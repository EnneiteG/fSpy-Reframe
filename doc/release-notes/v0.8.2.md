# fSpy Reframe 0.8.2

This release publishes the first cross-platform fSpy Reframe packages from the maintained fork.

## Changes

- Add Linux package outputs for AppImage, deb and rpm.
- Add unsigned macOS DMG outputs for Intel x64 and Apple Silicon arm64.
- Keep Windows NSIS installer and zip outputs, including the current-user/all-users installer choice introduced in 0.8.1.
- Add Linux and macOS GitHub Actions validation with packaged app smoke tests.
- Make the packaged app smoke test resolve Windows, Linux and macOS unpacked app layouts.

## Notes

- macOS packages are currently unsigned and not notarized. Users may need to allow the app manually in macOS security settings.
- Linux AppImage, deb and rpm packages are x64 builds.

## Validation

- Windows, Linux and macOS CI validate linting, builds, tests, packaging and packaged-app smoke launch before release assets are published.
